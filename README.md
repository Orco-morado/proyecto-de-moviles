# Gestión Móvil de Oportunidades y Activaciones Corporativas

## Descripción del Proyecto
Aplicación móvil desarrollada en Android Studio (Jetpack Compose) enfocada en mejorar la forma en que el equipo comercial identifica, organiza, prioriza y gestiona oportunidades de activación corporativa. MVP estructurado con arquitectura MVVM y persistencia de datos local mediante Room.

## Funcionalidades Implementadas
- Interfaz visual estructurada con Jetpack Compose y Material Design 3.
- Gestión de estado y arquitectura desacoplada mediante `StateFlow` y `ViewModel`.
- Formularios validados visualmente con retroalimentación en tiempo real e íconos de alerta.
- Almacenamiento local (persistencia) utilizando la librería Room para garantizar la disponibilidad de la información.
- Integración de recursos nativos del dispositivo, incluyendo acceso a la cámara para la captura de evidencias y geolocalización GPS.
- Animaciones visuales funcionales y transiciones fluidas mediante `AnimatedVisibility` para una mejor experiencia de usuario en la navegación y búsqueda.

## Pasos para Ejecutar
1. Clonar el repositorio en la máquina local.
2. Abrir el proyecto en Android Studio.
3. Esperar la sincronización de los archivos de Gradle.
4. Ejecutar la aplicación en un emulador Android o en un dispositivo físico conectado mediante depuración USB.
